# PS Med (Android)

An original Android medicine-directory prototype built with Kotlin and Jetpack Compose. It provides search by brand/generic name, strength and form; category filters; entry details; and a local favorites list.

## Open and run

1. Open this repository in Android Studio (Giraffe or newer recommended).
2. Allow Gradle sync to download the Android Gradle Plugin and dependencies.
3. Run the `app` configuration on an emulator or Android device (Android 7.0 / API 24 or newer).
